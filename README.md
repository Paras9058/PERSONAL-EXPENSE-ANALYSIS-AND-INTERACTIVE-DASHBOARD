# Personal Expense Analysis and Interactive Dashboard

## Project Description
This is a Python-based Data Science mini project that analyzes personal expenses and displays spending patterns using graphs and charts.

## Objectives
- Analyze expenses by category.
- Track monthly spending.
- Understand spending patterns.
- Help users manage their budgets.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Excel

## Features
- Category-wise expense analysis
- Monthly spending trend
- Expense distribution using a pie chart
- Bar graph for comparing expenses
- Horizontal bar graph for category comparison

## Graphs Used
1. Bar Graph
2. Line Graph
3. Pie Chart
4. Horizontal Bar Graph

## Dataset
The project uses an Excel dataset containing expense dates, categories, and amounts.

## How to Run
1. Download the project files.
2. Open the Jupyter Notebook file.
3. Install the required Python libraries.
4. Keep the Excel dataset in the same folder as the notebook.
5. Run the notebook cells in order.

## Learning Outcomes
Learned how to clean data, analyze expenses, group data by category, and visualize results using Python.
